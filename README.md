# Distance between Two Points Calculator

## Description
This program calculates the distance between two points.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values. (x1, x2, y1, y2)

## Input Needed
- x1 (The x-coordinate of the first point)
- x2 (The y-coordinate of the first point)
- y1 (The x-coordinate of the second point)
- y2 (The y-coordinate of the second point)

## Sample Output
Enter x1: 2

Enter y1: 3

Enter x2: 7

Enter y2: 8

The distance between the two points is:  7.07
